# R-Info (UNLP) - Guía y Referencia

Referencia interactiva de palabras clave, memoria interna, simulador lógico y sintaxis de R-Info.

## Cómo ejecutar

Al usar JavaScript con módulos nativos (`type="module"`), necesitás un servidor local:

### Python

```bash
python -m http.server 3000
```

### Node / npx

```bash
npx serve .
# o
npx http-server -p 3000
```

### VS Code

Clic derecho en `index.html` → **Open with Live Server**.

---
Abrí en tu navegador: [http://localhost:3000](http://localhost:3000)
